# Document Dashboard

A full-stack document management dashboard built with React, Express, Socket.IO, and Multer.

## Features

* Multi PDF Upload
* Real-time Upload Progress
* Smart Bulk Upload Notifications
* Real-time Notifications using Socket.IO
* Notification Center
* File Download Support
* Document Table

## Tech Stack

Frontend:

* React
* Axios
* Socket.IO Client

Backend:

* Node.js
* Express
* Multer
* Socket.IO

## Run Frontend

```bash
cd client
npm install
npm run dev
```

## Run Backend

```bash
cd server
npm install
node server.js
```

Frontend runs on:

```txt
http://localhost:5173
```

Backend runs on:

```txt
http://localhost:5000
```
